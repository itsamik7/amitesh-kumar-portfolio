# Amitesh Kumar — Portfolio

A modern, high-performance portfolio website for **Amitesh Kumar** (Strategy | Growth | Operations), built with React 19, TypeScript, Tailwind CSS v4, and Motion.

## 🚀 Overview

This portfolio showcases professional experience across strategy, revenue growth, and operations management, featuring:
- **Interactive Experience & Case Studies**: Deep dives into growth metrics, operational scaling, and zero-to-one business initiatives.
- **Featured Ventures**: Coverage of entrepreneurship and venture milestones.
- **Responsive & Dynamic Design**: Dark/Light mode theme toggle, smooth micro-interactions, custom cursor, and responsive layout.
- **Typography & Aesthetics**: Curated typography with high-contrast styling and fluid transitions.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git

# Navigate into project directory
cd <repo-name>

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```
The app will run locally at `http://localhost:3000` (or the port specified by Vite).

### Production Build

```bash
npm run build
```
This builds the production-optimized static files into the `dist/` folder.

### Preview Production Build

```bash
npm run preview
```

## 🌐 Deployment

This application is ready to be deployed on any modern static hosting platform:

- **Vercel**: Import the repository on [Vercel](https://vercel.com) — framework will be automatically detected as Vite.
- **Netlify**: Connect your GitHub repo to [Netlify](https://netlify.com) with build command `npm run build` and publish directory `dist`.
- **GitHub Pages**: Build the project and deploy the `dist/` directory via GitHub Actions or the `gh-pages` package.
